# UI 가이드 (시안 M1~M8 · T1~T7 기준, 2026-11-17 화면 이동 정리 반영)

이 문서는 지금까지 사용자와 나눈 UI 관련 대화·결정을 빠짐없이 모은 것이다. 새 프로젝트에서 화면을 만들 때 **이 문서와 `design/*.dc.html` 시안이 기준**이다. 시안과 다르게 만들고 싶으면 먼저 사용자에게 묻는다. "비슷하게" 만들지 말고 시안 그대로 옮긴다.

## 0. 가장 중요한 원칙 (사용자가 여러 번 강조한 것)

0. **★ 팝업 규칙 (2026-11-17 사용자 강조, 예외 없음)** — 앱의 **모든 팝업 상자·시트·인스펙터**는 ① **화면 아래에서 위로 미끄러져 올라오고**, ② **상자 바깥 아무 곳이나 탭하면 아래로 미끄러져 사라진다.** 닫기 버튼(⌄ / 완료 / 취소)은 있어도 되지만 바깥 탭으로 닫히지 않는 상자는 만들지 않는다. 화면이 멈춘 것처럼 상자가 남아 있으면 안 된다. 자세한 동작은 2.3.
0-1. **★ 화면 이동 규칙 (2026-11-17)** — 하단 탭바 **홈 · 배선 · 패널 · 점검 · 운영**은 **어느 화면에서든 항상** 보인다. 화면(페이지) 사이 이동은 **오직 이 탭바로만** 한다. 본문 안에 다른 페이지로 가는 버튼·링크(예: "상세 보기", "‹ 간략", "배선 편집" 칩)를 두지 않는다. 같은 페이지 안의 보기 전환(칩·드롭다운)만 허용.
0-2. **★ 머리 규칙 (2026-11-17)** — 모든 화면: **좌상단 = 지금 페이지 제목**(홈/배선/패널/점검/운영), **우상단 = "연결됨" 상태 표시(항상)**, 제목 **바로 아래 = 선택 칩**(패널은 칩 대신 드롭다운, 홈은 칩 없음).
0-3. **★ 목록에서 하나 고르기 = 드롭다운 (2026-11-17)** — 믹서·구역·소스처럼 여러 개 중 하나를 고르는 곳은 **스테퍼(‹ ›)를 쓰지 않고 드롭다운**으로 한다. 모양과 동작은 2.4.
1. **화면의 중심은 실물 믹서 그림이다.** 목록·표 중심 화면을 만들지 않는다. 점검 결과·원인 분석·알림은 **믹서 그림 위 배지(!)** 로 표시하고, 누르면 아래 둥근 박스에 설명이 뜬다. **예외(2026-11-17 사용자 승인): 점검 탭은 배지로 보이는 사항을 모은 목록**이다(4장 M8).
2. **"비슷한 그림"이 아니라 실물을 옮긴 그림.** 처음 쓰는 사람이 실물 믹서 앞에서 화면만 보고 바로 세팅할 수 있어야 한다. 패널 배치, 노브 캡 색, 눈금 글자, 단자 모양, 라벨 위치를 실물 사진 기준으로 맞춘다.
3. **소스를 합치지 않는다.** 사용자가 배선도에 하나씩 그려 둔 데는 이유가 있다. 베이스, 기타, 키보드, 드럼, 구즈넥 L, 구즈넥 R, 매립형 1, 매립형 2, 매립형 3, 무선, CD, PC를 **각각 별도 박스·별도 선**으로 그린다. ("키보드/드럼" 한 박스, "마이크 묶음" 같은 통합 표현 금지.)
4. **케이블이 서로 겹치거나 가로지르지 않게** 배치한다. 배선도(M7)와 앱(M1) 모두.
5. **홈(M1)과 전체 배선도(M7)는 같은 믹서 그림, 같은 케이블 배치**를 쓴다. M7은 M1의 ×2 확대 복사본이다. 한쪽을 고치면 다른 쪽도 같이 고친다.
6. **상세 화면에서 바꾼 값은 M1·M7의 믹서 그림에도 즉시 반영**되고 새로고침해도 유지된다.
7. **모바일 웹앱만** 만든다(데스크톱 레이아웃 없음). 태블릿은 같은 화면을 넓혀 쓰는 반응형(세로·가로). 태블릿 시안은 `design/Tab*.dc.html`(T1~T7, 아래 4.T).
8. 한국어 UI. 문장은 "~해요" 체. 쉬운 말(예: "노브를 올려요", "실물에 맞췄어요").
9. 아날로그 장비라 앱이 장비를 움직이지 못한다. 앱은 "실물을 이 위치로 돌리세요"를 알려 주고, 사람이 돌린 뒤 **"실물에 맞췄어요"** 로 확인한다.

## 2. 공통 화면 골격

### 2.1 하단 탭바 (모든 화면, 항상 표시)
- 5개: **홈 · 배선 · 패널 · 점검 · 운영**. 순서대로 `MobOverview`, `MobWiring`, `MobL4`(패널은 마지막에 본 믹서), `MobChecks`, `Mobile`.
- **모든 화면에 항상** 떠 있고(시트가 열려도 탭바는 그대로, `z-index`를 본문보다 위), **페이지 이동의 유일한 수단**이다(0장 0-1).
- `position:absolute; left:12px; right:12px; bottom:12px; height:56px; border-radius:28px`, 배경 `rgba(255,255,255,0.78)` + blur(20px), 외곽선 `0 0 0 0.5px var(--sep)`.
- 각 탭은 **아이콘(24px, 선 1.8, `currentColor`) + 글자** 세로 배치, 간격 2px. 아이콘 원본 `design/icons/tab-{home,wiring,panel,checks,operate}.svg` (2026-11-17 확정).
- 글자 11/13. 선택된 탭은 `background:var(--fill3); color:var(--accent); font-weight:600; border-radius:24px`.
- 본문은 탭바에 가리지 않게 아래 패딩 100px.

### 2.2 상단 (머리)
- 모든 화면 공통: 왼쪽 **페이지 제목**(34/41 bold: 홈 · 배선 · 패널 · 점검 · 운영), 오른쪽 **연결됨 알약**(초록 점 + "연결됨", 배경 `#dff5e3`, 13px). 연결이 끊기면 같은 자리에 "연결 끊김"(주의 색).
- 제목 바로 아래 줄 = **선택 칩**(알약 44px, 선택 칩은 `--accent` 바탕 + 흰 글자, 나머지 `--fill3`).
  - 홈: 칩 없음(홈 = 상세 보기 그 자체).
  - 배선: `케이블별 · 소스별 · 단자별` + 오른쪽 끝 `+`(케이블 추가).
  - 패널: 칩 대신 **드롭다운 2줄**(믹서 · 구역, 아래 4장 M2~M4).
  - 점검: `전체 N · 오류 N · 주의 N · 참고 N`(필터).
  - 운영: `시스템 시작하기 · 끝내기 · 소스별 소리 조정`(소스별이면 그 아래 소스 드롭다운).
- 예전 분할 컨트롤(간략 | 상세), `‹ 간략` 뒤로 버튼, 장비 알약 3개, 본문 안 이동 칩은 **폐기**.

### 2.3 ★ 팝업 컴포넌트 (인스펙터 · 정보 상자 · 시트 · 대화상자) — 모든 화면 공통 규칙

**이 규칙은 디자인 시스템의 최우선 컴포넌트 규칙이다(2026-11-17 사용자 강조).** 새 팝업을 만들 때도 반드시 이대로 한다.

| 항목 | 규칙 |
|---|---|
| 나타남 | 화면 **아래에서 위로** 미끄러져 올라온다. `sheetUp .28s cubic-bezier(.2,.8,.2,1)` (`translateY(100%)→0`, 투명도 0→1) |
| 사라짐 | **상자 바깥 아무 곳이나 탭** → **아래로 미끄러져** 사라진다. `sheetDown .22s ease-in forwards` (`0→translateY(110%)`, 투명도 1→0), 애니메이션이 끝난 뒤(220ms) 상태를 닫음으로 바꾼다 |
| 바깥 탭 판정 | 딤이 있는 시트: 딤(`rgba(0,0,0,0.4)`, `dimIn .2s` / `dimOut .22s`)을 탭하면 닫힘. 딤이 없는 상자(패널 인스펙터, 홈 정보 상자): 본문(main)을 탭했는데 그 대상이 버튼·링크·`role="button"`(노브·페이더·단자·소스 박스 등)이 **아니면** 닫힘. 다른 컨트롤을 탭하면 닫히지 않고 그 컨트롤로 내용이 바뀐다 |
| 닫기 버튼 | 있어도 된다(⌄, 완료, 취소). 눌러도 같은 아래로 미끄러지는 애니메이션 |
| 위치 | 하단 탭바 바로 위(`bottom:80px`, 좌우 12px), 탭바는 가리지 않는다. 모달 시트(배선)는 탭바 위까지 덮어도 되지만 딤 탭으로 닫힌다 |
| 모양 | 1.4의 시트 모양(둥근 28px 카드 또는 위만 둥근 18px 모달) |
| 확인 대화상자 | 되돌리기 어려운 동작(케이블 대체·삭제)만. 가운데 작은 카드(취소 · 실행), 딤 탭 = 취소 |
| 금지 | 바깥을 탭해도 남아 있는 상자, 위·옆에서 나타나는 상자, 애니메이션 없이 사라지는 상자, 접힌 알약 버튼으로 남는 상자 |

- 시안 구현: `closing` 상태 + `shut(patch)` 도우미(`closing:true` → 220ms 뒤 `closing:false` + 닫힘 적용), 스타일 `animation:{{sheetAnim}}`. `design/MobL4.dc.html`, `MobOverview`, `MobWiring`, `MobChecks`, `Mobile` 모두 같은 방식.
- 패널 인스펙터(M2~M4): 평소에는 숨겨 두고 노브·페이더·버튼을 **누를 때마다 올라온다**. 바깥(패널 빈 곳)을 탭하면 내려간다. **예전의 "우측 하단 파란 알약으로 접기"는 폐기**(2026-11-17).
- 본문은 팝업에 가려지지 않게 아래 여백(패널 520px, 홈 380px).
- **태블릿 예외(2026-11-17 사용자 결정)**: 태블릿 패널(T2~T4)의 인스펙터만 **오른쪽 고정 상자**다(4.T). 그 밖의 태블릿 팝업은 이 규칙을 그대로 따른다.

### 2.4 드롭다운 (스테퍼 대체, 2026-11-17)
- **버튼**: 알약 44px, 폭은 줄을 채움. 왼쪽에 지금 값(굵게) + 보조 글자(예: "DFX-12 · 메인 믹서", "마이크 입력 · 1 / 6", "소스 구즈넥 L → DFX-12 CH1 · 1 / 12"), 오른쪽 끝에 **28px 원형 쉐브론 캡**(⌄, `--accent`). 열리면 쉐브론이 위로 돈다(180°).
- **메뉴**: 버튼 바로 아래에 붙어서 펼쳐진다(`ddIn .18s`: 위에서 6px 내려오며 나타남). 둥근 16px 카드, 흰 반투명 + blur, 그림자 `0 10px 32px rgba(0,0,0,0.2)`. 행 높이 44~48px, 행 사이 0.5px 구분선, **지금 고른 항목은 굵게 + 오른쪽 파란 체크**. 항목이 많으면 그룹 제목(13px 보조색: 마이크 · 악기 · 재생)으로 나누고 메뉴 안에서 스크롤(최대 560px).
- **닫힘**: 항목을 고르면 바로 닫히고 적용. **메뉴 바깥 아무 곳이나 탭해도 닫힌다**(투명 막). 버튼을 다시 눌러도 닫힘.

## 3. 믹서 그림 (실물 재현 규칙)

세 믹서 모두 실물 사진 기준으로 도면을 SVG로 그렸다. 원본 좌표는 시안의 SVG에 있다. 앱에서는 이 SVG와 좌표·공식을 **프로파일 JSON**(`dfx12.json`, `ag06.json`, `l4.json`)으로 옮긴다.

### 3.1 배치
- 채널 순서, 노브·페이더·스위치·단자의 위치와 크기를 실물 기준으로 맞춘다.
- DFX-12 열 x좌표: 채널 8열(`103 + 62.5*i`), 리턴 페이더 603/677/745, 메인 L/R 803/838, 그래픽 EQ 5개 `607 + 35.5*i`.
- 전체 도면 배율(M1·M7): **AG06 ×0.26 @ (0,84)**, **L4 ×0.22 @ (206,84)**, **DFX-12 ×0.397 @ (0,388)**. M1 viewBox `0 0 358 940`, M7은 ×2 (W=800, H=2170).

### 3.2 노브
- 캡 색: **검정 GAIN, 흰색 HIGH·LOW(EQ), 노랑 EFF·RETURN·ECHO, 빨강 LEVEL·MAIN**. DFX-12 시안 값: GAIN `#f5f5f5`, EQ `#2f5fa8`(파랑), AUX `#b3243b`(빨강), PAN `#262626`.
- 지시선(포인터): 흰 캡이면 `#111`, 어두운 캡이면 `#fff`.
- 각도: 값 `v`(0~1)에 대해 **`rotate(-135 + 270*v)`**. 눈금 글자와 시작·끝 각도를 실물과 같게.
- 값 표기(상세 인스펙터): 시계 시각("11시", "12시 30분"), 0~10 눈금, 아날로그 값(dB). GAIN은 "약 N dB (마이크 입력 기준)", 톤은 ±15 dB, GRAPHIC EQ는 ±12 dB, PAN은 "왼쪽 N% / 중앙 / 오른쪽 N%", 페이더는 "N dB (U가 0 dB)" / "-∞", FX는 이름(SM. ROOM … SPRING 16종).
- 선택된 컨트롤은 **청록 링 `#2DD4BF`** 로 강조.

### 3.3 페이더
- 위치 `y = ya + yb*v`. DFX: `ya = fb-26`, `yb = -(fb-ft-26)`. L4: `ya=666`, `yb=-100`.
- 캡 색: 일반 `#f1f1f1`, AUX RETURN `#a31b3a`, MAIN `#2f5fa8`, EQ 슬라이더 `#e8e8e8`(폭 18, 일반은 28).

### 3.4 버튼/스위치 (MUTE, +48V, EQ, BYPASS 등)
- 28×16 알약.
- **켜짐**: 밝은 색(MUTE·+48V는 **빨강 `#E0332B`**, 그 외 **청록 `#2DD4BF`**) + 흰/짙은 글자 **"ON"** + 빛 번짐(glow).
- **꺼짐**: 어두운 회색 `#5E6166` + 글자 **"OFF"**.
- 켜짐 판정은 값 `v === 1`.
- 램프: 전원 램프(켜짐 `#E0332B` / 꺼짐 `#4A1A18`), 팬텀 램프(켜짐 `#F2C200` / 꺼짐 `#4D4A2A`), 채널 PEAK 램프 `#d8a800`.
- L4 팬텀 `ph1`: 켜짐 `#E0332B` / 꺼짐 `#5A2A2A`, `ph2`는 x 위치 389 ↔ 374로 이동.

### 3.5 단자 (잭)
- XLR 3핀: 바깥 원 r=21, 핀 3개(위 좌우 `(±8.5,-5)`, 아래 `(0,+11)` r=3).
- 6.35mm(5.5) 잭: r=14, 안쪽 구멍 r=6. 어두운 `#111` 바탕 + `#BDBDBD` 테두리.
- RCA: r=11, 구멍 r=4. **흰 `#F5F5F5` / 적 `#E0332B`** 로 L·R 구분.
- 헤드폰 잭(PHONES)도 실물 모양.
- 라벨 위치도 실물과 동일. **입력 단자에는 IN, 출력 단자에는 OUT 라벨을 항상** 표시. 컨트롤을 누르면 **입력 단자 → 노브·페이더 → 출력 단자**까지 점선 경로로 이어서 보여 준다(신호 흐름 표시). **입력 단자(어댑터)를 탭해도** 같은 점선이 뜬다: 그 채널의 첫 노브(보통 GAIN)를 선택하고, 인스펙터는 숨긴 채 우측 하단 버튼에 이름만 바뀐다(2026-11-17 사용자 결정).

### 3.6 이름 표기 (F18)
- **모든 노브·페이더·버튼·램프와 입력·출력 단자 아래에 실물 패널의 이름을 항상 표시**한다(숨기지 않는다). 단자는 커넥터 종류와 연결된 소스도 함께.
- DFX-12 열 위 소스 라벨은 청록 `#7DE0D0`: `← 구즈넥 L`, `← 구즈넥 R`, `← 매립형 1`, `← 매립형 2`, `← 매립형 3`, `← 무선`, 7번은 `← AG06`, 8번은 `(빈 입력)`.
- 출력 라벨은 주황 `#FDBA74`: `LEFT → QSC`, `RIGHT → QSC`, `PHONES → MPS1200`.
- 노브/페이더 이름은 짧게(예: GAIN, HI, LOW, AUX 1, AUX 2, PAN, MUTE, 로우컷, CH1…, 60/250/1K/3.5K/12K).

### 3.7 "미동기화"(실물 확인 필요) 표시
- 값을 바꾸면 해당 컨트롤에 **앰버 점**이 뜨고, 인스펙터에서 **"실물에 맞췄어요"** 를 누르면 사라진다.
- 현재 M1·M7 그림에는 이 앰버 점이 아직 안 나온다(미구현, 앱에서 구현할 것).

- 베이스(HEX B100) → DI BOX CH1 → AG06 CH1, 통기타 → DI BOX CH2 → AG06 CH2 (악기→DI는 5.5 TS, DI→AG06은 XLR).
- 케이블 이름은 시작 쪽 단자만 적어요(예: DI BOX CH1 출력, 베이스 (HEX B100)). 꽂힌 곳·위쪽 소스는 이름에 넣지 않고, 아래 줄에 지금 꽂힌 단자로 보여요(2026-11-18 사용자 결정).
- **키보드(MGX-230): TRS 출력 → TS 2줄(Y케이블) → AG06 CH3/4 L/MONO·R (스테레오).**
- **전자 드럼(Alesis Nitro Mesh): TS 모노 2줄(L·R) → RCA로 변환 → AG06 CH5/6 L·R.**
- AG06 STEREO OUT → DFX-12 CH9/10 (5.5 TS L·R). DFX CH11/12는 비어 있음.
- L4 CH1/2: CD 플레이어, RCA to RCA 2줄 + TS 어댑터(스테레오). L4 CH3/4: PC(OBS), AUX(3.5mm) to RCA(스테레오).
- L4 MAIN OUT L·R → DFX-12 CD/TAPE IN (2×5.5 TS to RCA).
- DFX-12 MAIN OUT L·R → QSC (XLR) → 메인 스피커 L·R → 모니터 스피커 L·R(메인에서 이어짐).
- DFX-12 PHONES → MPS1200 (5.5 TS) → 자모실 스피커. (MPS1200 CH1 고장, 자모실 스피커가 CH1인지 확인 필요)
- DFX-12 TAPE OUT, AUX SEND 1/2는 쓰지 않음.

### 케이블 그리기 규칙
- 종류별 **선 색·굵기·끝 모양**을 다르게(XLR, 5.5 TS, RCA 적·백). 양 끝에 장비·단자 이름 표기.
- AG06 → DFX 9/10: **주황 점선**, L·R 두 줄이 겹치지 않게 간격을 둔다.
- L4 MAIN OUT → DFX TAPE IN: 회색선(L, 흰 RCA) + 빨간선(R, 적 RCA).
- DFX MAIN OUT → QSC: 두 줄 나란히. PHONES → MPS1200: 별도 경로. 하단 박스(QSC, MPS 같은 y, 스피커, 모니터 순서로 아래).
- 선 경로는 직각(V/H) 위주로 그려 교차를 피한다. 새 케이블을 추가할 땐 기존 선과 안 겹치는 통로를 먼저 정한다.
- 소스 박스 → 믹서 입력 사이도 겹치지 않게(마이크 줄 A/B를 위·아래로 나눈 이유).

## 6. 점검·배지 규칙 (UI로 보이는 방식)

규칙(오류·주의·참고): 빈 입력, 팬텀 전원, 모노/스테레오, 케이블 종류, 경로 끊김, 이중 연결, 레벨 이상, 전원 순서.
현재 시스템 예: DFX CH11/12 빈 입력 → 페이더 최소 권장 / AG06 1번 +48V ON·패시브 DI면 끄기 / 키보드(3/4)·드럼(5/6)은 L·R 두 줄 모두 꽂혀야 스테레오(한 줄이면 경고) / L4→TAPE IN은 2×5.5 TS→RCA / MPS1200 CH1 고장 → 자모실 경로 경고 / 키보드가 3/4와 5/6에 동시에 꽂혔는지 / PEAK 램프·GAIN 최대 근처 / 앰프가 믹서보다 먼저 켜지면 경고.
표시: **믹서 그림 위 배지(!)** → 누르면 아래 둥근 박스에 원인과 확인할 것. 같은 항목을 **점검 탭(M8)에 목록**으로도 모은다(2026-11-17 사용자 승인으로 예전 "점검 목록 화면 금지"를 바꿈).

## 7. 상호작용·상태 동작

- **실시간 반영**: 노브/페이더를 조작하는 같은 프레임에 값(시각·눈금·dB), 신호 경로(끊긴 곳은 빨강), 레벨 미터(PEAK/CLIP 모사), 점검 알림이 함께 갱신된다.
- **공유 상태**: 상세 화면의 값은 저장소(localStorage `mixsync:ag|dfx|l4` = `{vals, synced, phantom, t}`; 가능하면 서버 문서 `mixer/<board>`에도 500ms 디바운스로 기록)에 저장되고, M1·M7은 변경 이벤트·주기 폴링·구독으로 읽어 믹서 그림의 노브 각도·페이더 높이·버튼 ON/OFF·팬텀 값을 갱신한다.
- **연결이 끊겨도 마지막 화면을 유지**한다(오프라인 지원은 안 하지만 화면을 지우거나 오류 화면으로 바꾸지 않는다). 다시 연결되면 최신 값을 불러온다.
- 접근: URL만 알면 누구나(로그인 없음). 모든 변경은 즉시 저장. 동시 접속 3명 이하.
- 노브를 돌리는 값 입력은 시계 시각(11시)과 0~10 눈금을 함께 보여 준다(어느 쪽을 입력 기준으로 할지는 열린 질문).
- 안내 방식: 값을 고르면 해당 노브가 강조되고 **"시계 12시 방향", "눈금 6.5"** 처럼 실물 눈금 기준으로 말해 준다.
- 비교 보기: 실물 사진과 트윈을 나란히(또는 겹쳐) 보고 어긋난 곳을 확인(후속).
- 구역 이동: 패널의 구역 드롭다운에서 고르면 패널이 해당 위치로 부드럽게 스크롤.

## 8. 사용자가 지적했던 것 / 하지 말 것 (재발 방지)

1. "소스를 누가 합쳐버리래" → 소스를 합쳐 그리지 않는다(0장 3번).
2. 간략 보기에 **전체 배선도와 같은 믹서 이미지와 선 연결**을 넣어 달라고 요청함 → 별도 단순 도형 금지.
3. 배선이 겹치거나 교차하면 안 된다(도면·앱 모두).
4. 키보드는 TRS 한 줄이 아니라 **TS 두 줄로 갈라서** AG06 3/4(L·R)에 들어간다. 드럼은 **TS 모노 2줄 → RCA → AG06 5/6**. 키보드를 5/6에 넣거나 드럼을 3/4에 넣지 말 것.
5. 상세 화면에서 노브를 돌렸는데 간략 보기·전체 배선도의 믹서 그림에 반영 안 되던 문제 → 공유 상태(7장)로 해결. 새 앱에서도 반드시 같은 저장값을 읽게 한다.
6. 노브/버튼 ON-OFF 표시를 한눈에 구분되게(3.4).
7. 입력 IN / 출력 OUT 라벨과 점선 경로 표시(3.5).
8. 모든 컨트롤·단자 아래 이름 표기(3.6).
9. 핀치 확대·축소는 M7뿐 아니라 **홈(M1)과 패널(M2~M4)** 에서도 지원(+/− 버튼 포함, 패널은 상하좌우 이동). "믹서별 상세보기 확대·이동이 막혀 있다"는 지적(2026-11-17).
10. 터치 영역 44px 미만으로 만들지 않는다. 작은 글자(11~12px)는 보조 정보에만.
11. 데스크톱 레이아웃을 만들지 않는다.
12. 아티팩트(시안) 수정은 사용자에게 허락을 묻지 않고 바로 반영한다.
13. "패널 위 팝업 상자가 안 사라진다" → 모든 팝업은 바깥 탭으로 아래로 사라진다(2.3).
14. "유저 플로우가 난잡하다" → 페이지 이동은 하단 탭바로만, 머리는 좌상단 제목 · 우상단 연결됨 · 아래 칩(0장 0-1, 0-2).
15. 이미 꽂힌 단자를 못 고르던 문제 → 고를 수 있고, 확인 후 대체 + 실행취소(M5).
