# UI 가이드 (시안 M1~M7 기준, 2026-11-17)

이 문서는 지금까지 사용자와 나눈 UI 관련 대화·결정을 빠짐없이 모은 것이다. 새 프로젝트에서 화면을 만들 때 **이 문서와 `design/*.dc.html` 시안이 기준**이다. 시안과 다르게 만들고 싶으면 먼저 사용자에게 묻는다. "비슷하게" 만들지 말고 시안 그대로 옮긴다.

시안 원본: 캔버스 https://claude.ai/artifact/71UHP6YnnwUcrze2apQtFu (저장소 `design/`).
명세서: https://claude.ai/artifact/9KErfNfunVGja9xz9bjEjy (F3·F4·F5·F17·F18·F19·F20 및 "실물 재현 원칙", "화면 구성").

## 0. 가장 중요한 원칙 (사용자가 여러 번 강조한 것)

1. **화면의 중심은 실물 믹서 그림이다.** 목록·표 중심 화면을 만들지 않는다. 점검 결과·원인 분석·알림도 별도 목록 화면 없이 **믹서 그림 위 배지(!)** 로 표시하고, 누르면 아래 둥근 박스에 설명이 뜬다.
2. **"비슷한 그림"이 아니라 실물을 옮긴 그림.** 처음 쓰는 사람이 실물 믹서 앞에서 화면만 보고 바로 세팅할 수 있어야 한다. 패널 배치, 노브 캡 색, 눈금 글자, 단자 모양, 라벨 위치를 실물 사진 기준으로 맞춘다.
3. **소스를 합치지 않는다.** 사용자가 배선도에 하나씩 그려 둔 데는 이유가 있다. 베이스, 기타, 키보드, 드럼, 구즈넥 L, 구즈넥 R, 매립형 1, 매립형 2, 매립형 3, 무선, CD, PC를 **각각 별도 박스·별도 선**으로 그린다. ("키보드/드럼" 한 박스, "마이크 묶음" 같은 통합 표현 금지.)
4. **케이블이 서로 겹치거나 가로지르지 않게** 배치한다. 배선도(M7)와 앱(M1) 모두.
5. **간략 보기(M1)와 전체 배선도(M7)는 같은 믹서 그림, 같은 케이블 배치**를 쓴다. M7은 M1의 ×2 확대 복사본이다. 한쪽을 고치면 다른 쪽도 같이 고친다.
6. **상세 화면에서 바꾼 값은 M1·M7의 믹서 그림에도 즉시 반영**되고 새로고침해도 유지된다.
7. **모바일 웹앱만** 만든다(데스크톱 레이아웃 없음). 태블릿은 같은 화면을 넓혀 쓰는 반응형(세로·가로). 태블릿 시안은 `design/Tab*.dc.html`(T1~T6, 아래 4.T).
8. 한국어 UI. 문장은 "~해요" 체. 쉬운 말(예: "노브를 올려요", "실물에 맞췄어요").
9. 아날로그 장비라 앱이 장비를 움직이지 못한다. 앱은 "실물을 이 위치로 돌리세요"를 알려 주고, 사람이 돌린 뒤 **"실물에 맞췄어요"** 로 확인한다.

## 3. 믹서 그림 (실물 재현 규칙)

세 믹서 모두 실물 사진 기준으로 도면을 SVG로 그렸다. 원본 좌표는 시안의 SVG에 있다. 앱에서는 이 SVG와 좌표·공식을 **프로파일 JSON**(`dfx12.json`, `ag06.json`, `l4.json`)으로 옮긴다.

### 3.1 배치
- 채널 순서, 노브·페이더·스위치·단자의 위치와 크기를 실물 기준으로 맞춘다.
- DFX-12 열 x좌표: 채널 8열(`103 + 62.5*i`), 리턴 페이더 603/677/745, 메인 L/R 803/838, 그래픽 EQ 5개 `607 + 35.5*i`.
- 전체 도면 배율(M1·M7): **AG06 ×0.26 @ (0,84)**, **L4 ×0.22 @ (206,84)**, **DFX-12 ×0.397 @ (0,388)**. M1 viewBox `0 0 358 940`, M7은 ×2 (W=800, H=2170).

### 3.2 노브
- 캡 색: **검정 GAIN, 흰색 HIGH·LOW(EQ), 노랑 EFF·RETURN·ECHO, 빨강 LEVEL·MAIN**. DFX-12 시안 값: GAIN `#f5f5f5`, EQ `#2f5fa8`(파랑), AUX `#b3243b`(빨강), PAN `#262626`.
- 지시선(포인터): 흰 캡이면 `#111`, 어두운 캡이면 `#fff`.
- 각도: 값 `v`(0~1)에 대해 **`rotate(-135 + 270*v)`**. 눈금 글자와 시작·끝 각도를 실물과 같게.
- 값 표기(상세 인스펙터): 시계 시각("11시", "12시 30분"), 0~10 눈금, 아날로그 값(dB). GAIN은 "약 N dB (마이크 입력 기준)", 톤은 ±15 dB, GRAPHIC EQ는 ±12 dB, PAN은 "왼쪽 N% / 중앙 / 오른쪽 N%", 페이더는 "N dB (U가 0 dB)" / "-∞", FX는 이름(SM. ROOM … SPRING 16종).
- 선택된 컨트롤은 **청록 링 `#2DD4BF`** 로 강조.

### 3.3 페이더
- 위치 `y = ya + yb*v`. DFX: `ya = fb-26`, `yb = -(fb-ft-26)`. L4: `ya=666`, `yb=-100`.
- 캡 색: 일반 `#f1f1f1`, AUX RETURN `#a31b3a`, MAIN `#2f5fa8`, EQ 슬라이더 `#e8e8e8`(폭 18, 일반은 28).

### 3.4 버튼/스위치 (MUTE, +48V, EQ, BYPASS 등)
- 28×16 알약.
- **켜짐**: 밝은 색(MUTE·+48V는 **빨강 `#E0332B`**, 그 외 **청록 `#2DD4BF`**) + 흰/짙은 글자 **"ON"** + 빛 번짐(glow).
- **꺼짐**: 어두운 회색 `#5E6166` + 글자 **"OFF"**.
- 켜짐 판정은 값 `v === 1`.
- 램프: 전원 램프(켜짐 `#E0332B` / 꺼짐 `#4A1A18`), 팬텀 램프(켜짐 `#F2C200` / 꺼짐 `#4D4A2A`), 채널 PEAK 램프 `#d8a800`.
- L4 팬텀 `ph1`: 켜짐 `#E0332B` / 꺼짐 `#5A2A2A`, `ph2`는 x 위치 389 ↔ 374로 이동.

### 3.5 단자 (잭)
- XLR 3핀: 바깥 원 r=21, 핀 3개(위 좌우 `(±8.5,-5)`, 아래 `(0,+11)` r=3).
- 6.35mm(5.5) 잭: r=14, 안쪽 구멍 r=6. 어두운 `#111` 바탕 + `#BDBDBD` 테두리.
- RCA: r=11, 구멍 r=4. **흰 `#F5F5F5` / 적 `#E0332B`** 로 L·R 구분.
- 헤드폰 잭(PHONES)도 실물 모양.
- 라벨 위치도 실물과 동일. **입력 단자에는 IN, 출력 단자에는 OUT 라벨을 항상** 표시. 컨트롤을 누르면 **입력 단자 → 노브·페이더 → 출력 단자**까지 점선 경로로 이어서 보여 준다(신호 흐름 표시). **입력 단자(어댑터)를 탭해도** 같은 점선이 뜬다: 그 채널의 첫 노브(보통 GAIN)를 선택하고, 인스펙터는 숨긴 채 우측 하단 버튼에 이름만 바뀐다(2026-11-17 사용자 결정).

### 3.6 이름 표기 (F18)
- **모든 노브·페이더·버튼·램프와 입력·출력 단자 아래에 실물 패널의 이름을 항상 표시**한다(숨기지 않는다). 단자는 커넥터 종류와 연결된 소스도 함께.
- DFX-12 열 위 소스 라벨은 청록 `#7DE0D0`: `← 구즈넥 L`, `← 구즈넥 R`, `← 매립형 1`, `← 매립형 2`, `← 매립형 3`, `← 무선`, 7번은 `← AG06`, 8번은 `(빈 입력)`.
- 출력 라벨은 주황 `#FDBA74`: `LEFT → QSC`, `RIGHT → QSC`, `PHONES → MPS1200`.
- 노브/페이더 이름은 짧게(예: GAIN, HI, LOW, AUX 1, AUX 2, PAN, MUTE, 로우컷, CH1…, 60/250/1K/3.5K/12K).

### 3.7 "미동기화"(실물 확인 필요) 표시
- 값을 바꾸면 해당 컨트롤에 **앰버 점**이 뜨고, 인스펙터에서 **"실물에 맞췄어요"** 를 누르면 사라진다.
- 현재 M1·M7 그림에는 이 앰버 점이 아직 안 나온다(미구현, 앱에서 구현할 것).

## 4. 화면별 상세

  - 경로별 강조 대상 예: 베이스·기타·키보드·드럼 → `AG06 + 연결 케이블`, CD·PC → `L4 + 연결 케이블`, 마이크류 → `DFX-12 해당 입력`.
- **하단 정보 박스**(둥근 카드): 제목 + 상태 배지 + 3줄 설명 + "상세 보기" 이동 버튼. 소스 선택 시 "신호 흐름 · ○○" 제목, 단계 칩(예: 베이스 → DI BOX (베이스) → AG06 CH1 (+48V ON) → AG06 STEREO OUT → DFX-12 9/10)을 상태 색으로 보여 준다. 해당 장비 상세 화면으로 가는 버튼 포함("AG06 상세 보기" 등).
- **점검·원인 분석 배지**를 믹서/앰프/스피커 위에 표시. 시안의 이슈 예: AG06 "주의 1"(+48V ON·패시브 DI), L4 "정상", DFX-12 "참고 1"(11/12번 비어 있음), QSC "주의 · 이슈 #1 R 스피커가 약해요", MPS1200 "오류 · CH1 고장".
- 상태 표시는 목록이 아니라 배지(!)로. 누르면 아래 박스에 설명.

  2. (있으면) **신호 흐름** 박스: "신호 흐름 · …".

### M5. 배선·케이블 편집 — `MobWiring.dc.html`
- 제목 "배선" + 오른쪽 `+` 원형 버튼(케이블 추가). 아래줄: 저장 상태 텍스트("모든 변경은 즉시 저장") + **실행취소** 알약.
- 분할 컨트롤 **케이블별 | 단자별 소스**.
- 변경이 있으면 주황 안내 카드(`#ff8d2829`): "**N개 케이블이 바뀌었어요.** 실물 케이블도 같은 단자로 옮겨 주세요."
- **케이블별**: 그룹(제목 13px 대문자) 안에 행(최소 높이 60): 케이블 색 점(XLR `#1d1d1f`, TS `#6e6e73`, RCA `#ff383c`) + 출발("시작 단자") / `→` 도착 / 규격 줄(커넥터·암수·스테레오) + 오른쪽 종류 칩(변경되면 "변경됨" 주황 칩).
- 행을 누르면 **케이블 편집 시트**(위가 둥근 모달): 양끝 장비·단자를 그림으로, 양 끝 커넥터 모양(XLR 3핀, RCA, TRS 동심원, TS)과 **숫놈/암놈**·신호(모노/스테레오/평형) 표시, 반대쪽 단자 후보 목록. 커넥터가 맞는 단자만 후보로 보여 주고, **이미 쓰는 단자는 사용 이유와 함께 비활성화**. 다른 장비로 옮기면 경고("다른 장비로 옮기는 변경이에요. 채널 이름과 점검 규칙이 새 연결에 맞춰 다시 계산돼요.").
- **단자별 소스**: 단자 행(최소 52)에 현재 소스 표시, 누르면 소스 변경. 소스를 옮기면 **L·R 짝 선과 필요한 어댑터를 추천**.
- 모든 변경은 **즉시 저장 + 실행취소**.
- 현재 연결 규칙(아래 5장)을 시안 데이터와 정확히 같게.
- 구현(2026-11-17): 앱은 시안 코드(`design/MobWiring.dc.html` → `app/src/data/logic/wiring.js`)를 그대로 실행한다. 저장은 공유 저장소 키 `wiring` = `{cur, at, t}`(케이블 id → 단자 id, 300ms 뒤 저장, 다른 기기와 4초 폴링 공유).
- **케이블 추가·삭제 (2026-11-17 사용자 결정)**: `+`를 누르면 "케이블 추가" 시트(왼쪽 "취소", 오른쪽 "추가")가 뜬다. 순서는 ① 케이블 종류(XLR · 5.5 TS · RCA) ② 시작 쪽 장비 이름과 단자·설명(기존 장비 빠른 선택 칩) ③ 도착 단자다. 도착 후보는 편집 시트와 같은 규칙으로, 같은 커넥터만 보이고 이미 쓰는 단자는 "사용 중: ○○"으로 비활성이다. 추가한 케이블은 "추가한 케이블" 그룹에 들어간다. "케이블 삭제…"를 누르면 확인 대화상자("케이블을 삭제할까요?" / 취소 · 삭제)가 뜨고, 삭제 후에는 실행취소로 되돌린다. 추가·삭제도 변경 개수 안내 카드에 포함되고, 저장 키 `wiring`의 `added`(추가한 케이블)·`removed`(삭제한 기본 케이블 id)로 공유된다.

규칙(오류·주의·참고): 빈 입력, 팬텀 전원, 모노/스테레오, 케이블 종류, 경로 끊김, 이중 연결, 레벨 이상, 전원 순서.
현재 시스템 예: DFX CH11/12 빈 입력 → 페이더 최소 권장 / AG06 1번 +48V ON·패시브 DI면 끄기 / 키보드(3/4)·드럼(5/6)은 L·R 두 줄 모두 꽂혀야 스테레오(한 줄이면 경고) / L4→TAPE IN은 2×5.5 TS→RCA / MPS1200 CH1 고장 → 자모실 경로 경고 / 키보드가 3/4와 5/6에 동시에 꽂혔는지 / PEAK 램프·GAIN 최대 근처 / 앰프가 믹서보다 먼저 켜지면 경고.
표시: **믹서 그림 위 배지(!)** → 누르면 아래 둥근 박스에 원인과 확인할 것. 별도 "점검 목록" 화면을 만들지 않는다.

## 7. 상호작용·상태 동작

- **실시간 반영**: 노브/페이더를 조작하는 같은 프레임에 값(시각·눈금·dB), 신호 경로(끊긴 곳은 빨강), 레벨 미터(PEAK/CLIP 모사), 점검 알림이 함께 갱신된다.
- **공유 상태**: 상세 화면의 값은 저장소(localStorage `mixsync:ag|dfx|l4` = `{vals, synced, phantom, t}`; 가능하면 서버 문서 `mixer/<board>`에도 500ms 디바운스로 기록)에 저장되고, M1·M7은 변경 이벤트·주기 폴링·구독으로 읽어 믹서 그림의 노브 각도·페이더 높이·버튼 ON/OFF·팬텀 값을 갱신한다.
- **연결이 끊겨도 마지막 화면을 유지**한다(오프라인 지원은 안 하지만 화면을 지우거나 오류 화면으로 바꾸지 않는다). 다시 연결되면 최신 값을 불러온다.
- 접근: URL만 알면 누구나(로그인 없음). 모든 변경은 즉시 저장. 동시 접속 3명 이하.
- 노브를 돌리는 값 입력은 시계 시각(11시)과 0~10 눈금을 함께 보여 준다(어느 쪽을 입력 기준으로 할지는 열린 질문).
- 안내 방식: 값을 고르면 해당 노브가 강조되고 **"시계 12시 방향", "눈금 6.5"** 처럼 실물 눈금 기준으로 말해 준다.
- 비교 보기: 실물 사진과 트윈을 나란히(또는 겹쳐) 보고 어긋난 곳을 확인(후속).
- 키보드 순서·탭 이동: 구역 칩을 누르면 패널이 해당 위치로 부드럽게 스크롤.

## 8. 사용자가 지적했던 것 / 하지 말 것 (재발 방지)

1. "소스를 누가 합쳐버리래" → 소스를 합쳐 그리지 않는다(0장 3번).
2. 간략 보기에 **전체 배선도와 같은 믹서 이미지와 선 연결**을 넣어 달라고 요청함 → 별도 단순 도형 금지.
3. 배선이 겹치거나 교차하면 안 된다(도면·앱 모두).
4. 키보드는 TRS 한 줄이 아니라 **TS 두 줄로 갈라서** AG06 3/4(L·R)에 들어간다. 드럼은 **TS 모노 2줄 → RCA → AG06 5/6**. 키보드를 5/6에 넣거나 드럼을 3/4에 넣지 말 것.
5. 상세 화면에서 노브를 돌렸는데 간략 보기·전체 배선도의 믹서 그림에 반영 안 되던 문제 → 공유 상태(7장)로 해결. 새 앱에서도 반드시 같은 저장값을 읽게 한다.
6. 노브/버튼 ON-OFF 표시를 한눈에 구분되게(3.4).
7. 입력 IN / 출력 OUT 라벨과 점선 경로 표시(3.5).
8. 모든 컨트롤·단자 아래 이름 표기(3.6).
9. 핀치 확대·축소는 M7에서 지원.
10. 터치 영역 44px 미만으로 만들지 않는다. 작은 글자(11~12px)는 보조 정보에만.
11. 데스크톱 레이아웃을 만들지 않는다.
12. 아티팩트(시안) 수정은 사용자에게 허락을 묻지 않고 바로 반영한다.
